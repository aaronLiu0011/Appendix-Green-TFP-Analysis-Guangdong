# Data and publication policy

This repository publishes methodological documentation only.

## Included

- The theoretical framework for GTFP measurement.
- Mathematical definitions of the environmental production technology, directional distance function, SBM, and productivity decompositions.
- General descriptions of variable construction and index interpretation.

## Excluded

- The manuscript and online appendix.
- Raw statistical yearbook extracts or third-party datasets.
- The cleaned GTFP input panel and regression panel.
- City-year empirical GTFP results, paper tables, and figures.
- Source code, tests, input templates, and detailed implementation instructions.
- Proprietary software files, configuration files, and local software output.

Users must construct or obtain their own data and comply with the original data providers' licensing and citation terms.
