# Data and publication policy

This repository publishes computation code and methodological documentation only.

## Included

- Source code for the SBM linear program.
- Source code for adjacent-period ML, EC, and TC calculations.
- Mathematical definitions and a mapping to the archived MaxDEA settings.
- Unit tests based on small synthetic values.
- A header-only input schema.

## Excluded

- The manuscript and online appendix.
- Raw statistical yearbook extracts or third-party datasets.
- The cleaned GTFP input panel.
- The regression panel.
- City-year empirical GTFP results and paper tables.
- Local software output, temporary files, and proprietary MaxDEA files.

Users must construct or obtain their own data and comply with the original data providers' licensing and citation terms.
