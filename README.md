# GTFP Measurement Methodology

This repository provides an English-language theoretical account of green total factor productivity (GTFP) measurement with undesirable outputs.

The main document covers:

- the input, desirable-output, and undesirable-output structure;
- contemporaneous, sequential, and global environmental production technologies;
- the directional distance function and Malmquist–Luenberger index;
- the non-oriented undesirable-output slacks-based measure;
- efficiency-change and technical-change decompositions; and
- interpretation and methodological consistency.

Read the full methodology:

- [Theoretical Framework for GTFP Measurement](docs/DETAILED_METHOD.md)

This repository does not publish the manuscript, empirical data, numerical results, proprietary software files, or detailed code implementations.
